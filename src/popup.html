3自動チェックイン・コード交換

このブラウザの HoYoLAB / Skport ログインを使って、デイリーチェックインの受取と、HoYoLAB の新しいギフトコードの交換（3時間ごと）を自動で行います。いずれも任意設定で、既定はオフです。

ゲームごとに「表示」と「自動」のオン／オフを切り替えられます。表示をオフにしたゲームは、この画面にも自動処理にも出てきません。

報酬は各ゲーム内のメールに届きます。チェックインは HoYoLAB が毎日 01:05、エンドフィールドが毎日 05:05、コード確認は3時間ごとです。

状態を読み込んでいます…

    ペアリング連携では、HoYoLAB のセッション Cookie （ltuid_v2 / ltoken_v2 / ltmid_v2）を連携の操作をしたときだけ api.ivrm.jp へ送ります。自動連携では、ポータルの連携ページで本人がボタンを押したときに発行される短時間のトークンを、この拡張がページから受け取って同じ連携を行います（コードの目視コピーが不要になるだけで、送るものは変わりません）。連携時にポータルが読み取り専用のトークンを返した場合は、そのトークンをこのブラウザに保存し、現在の状況（樹脂・開拓力など）の取得にだけ使います。連携し直すかポータルで連携を解除すると、前のトークンは使えなくなります。自動チェックイン・コード交換では HoYoLAB の Cookie の値を読んだり保存したりせず、ブラウザのログイン状態のまま公式 API（hoyolab.com / hoyoverse.com）とコード一覧の hoyo-codes へだけ通信します。エンドフィールドでは、Skport のログイン Cookie（ACCOUNT_TOKEN）を読み取り、公式の Gryphline / Skport API へだけ送ってセッション資格情報に交換します。交換した資格情報や Cookie の値は保存しません。自動機能の設定・交換履歴・実行ログは、このブラウザの中にだけ保存されます。
