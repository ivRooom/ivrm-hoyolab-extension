# ストア掲載文案（読み取り専用版）

## 名称（案）

**本命: 「ivRooom 樹脂メモ（非公式）」**

- 理由: 運営主体（ivRooom）を冠しつつ、公式と誤認されないよう「（非公式）」を名称自体に入れる。「HoYoLAB」「原神」などの商標を名称の主部に使わない。
- 代替案: 「樹脂と開拓力メモ by ivRooom（非公式）」／「ivRooom ステータスメモ（非公式）」

## 短い説明（manifest の description と一致させる）

> ivRooom ポータルと連携して、原神の樹脂と崩壊：スターレイルの開拓力の回復状況を表示する、読み取り専用の非公式ファンメイド拡張機能です。ゲームへの操作は一切行いません。

## 詳しい説明（ストア掲載文）

```
原神の樹脂、崩壊：スターレイルの開拓力——「あとどれくらいで全回復するか」を、ゲームを起動せずにブラウザから確認できます。

「ivRooom 樹脂メモ（非公式）」は、コミュニティポータル「ivRooom ポータル」と連携して、ポータルが取得したあなたのゲームステータスを表示する、読み取り専用の拡張機能です。

■ 使い方
1. ivRooom ポータルで HoYoLAB 連携を行い、「連携トークン」を発行します
2. 本拡張のポップアップにトークンを貼り付けます
3. 以後はポップアップを開くだけで、樹脂・開拓力の現在の値と回復状況、探索度、最終取得時刻が確認できます

■ 安心ポイント
・読み取り専用：ゲームへの操作（チェックインやアイテム交換など）は一切行いません
・ログイン情報は扱いません：HoYoLAB の Cookie やパスワードを読み取る権限自体がありません
・通信先はポータルだけ：あなたのポータル（api.ivrm.jp）以外へデータを送りません
・トラッキングなし：広告・アクセス解析は含まれていません

■ ご注意
・本拡張の利用には ivRooom ポータルのアカウントとゲーム連携が必要です
・表示される値はポータルが最後に取得した時点のもので、ゲーム内の現在値と数分程度ずれる場合があります
・本拡張は ivRooom による非公式のファンメイドツールです。HoYoverse / HoYoLAB 公式とは関係ありません
```

## スクリーンショット計画

ストア要件: 1280×800（または 640×400）を最低1枚、最大5枚。ポップアップ単体は小さいため、ブラウザウィンドウ全体（1280×800）で撮影し、ポップアップを開いた状態を切り出すか、背景にポータルの画面を敷いた合成で用意します。撮影はステータス表示機能（Issue #3）が本番で動いてから行います（プレースホルダ表示の画面は使いません）。

| # | 状態 | 撮るもの | キャプション案 |
|---|---|---|---|
| 1 | 連携済み・ステータス表示 | 樹脂/開拓力のバーと探索度が見えるポップアップ | 開くだけで樹脂と開拓力の回復状況が分かります |
| 2 | 未連携（初期状態） | 連携トークンの案内と手順が見える状態 | ポータルで発行したトークンを貼るだけ |
| 3 | 連携ページ案内 | ポータルの連携ページと並べた状態 | ivRooom ポータルと連携して使います |
| 4 | （任意）ダークな全体像 | ポータルのゲームタブとポップアップの併記 | ポータルのゲーム連携と連動します |
